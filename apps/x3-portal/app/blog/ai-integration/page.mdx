## Getting Started with AI-Enhanced Development

1. **Enable AI Features** in your `atlas.config`:
```toml
[ai]
enable = true
model_package = "x3ai-core-v2"
```

2. **Annotate Contracts** for optimization:
```solidity
// @x3ai-optimize
contract HighFrequencyTrading {
    // AI will optimize execution path
}
```
