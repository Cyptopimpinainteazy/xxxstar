# X3 Examples

| File | Description |
|------|-------------|
| `arb_solana_eth.x3` | Arbitrage intent across Solana and Ethereum via X3 bridge |
| `atomic_swap.x3` | Atomic swap between ETH and SOL using HTLC |
| `timeout_refund.x3` | Intent with timeout-based refund mechanism |
| `flagship_b52.x3` | **Flagship B-52 example** — exercises all B-52 feature lock items: VM declarations, solver market, relayer swarm, RPC quorum, risk policy, privacy, invariants, proof requirements, finality policy, error decls, VM targets, and a full cross-VM intent |
| `simple_swap.x3` | Minimal intent exercising basic B-52 from/to/route/require/timeout patterns |
| `multi_leg_route.x3` | Multi-leg portfolio route with allocation to 4 destinations via swap + bridge |
| `staking_intent.x3` | Cross-VM staking intent with finality requirements |
