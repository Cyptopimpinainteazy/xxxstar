# V3 verification boundary

See [the funding integrity test report](V2_TEST_REPORT.md) for executed commands,
results and artifact paths. That milestone proves transactional funding state
integrity on PostgreSQL, not the complete V3 research platform.

The [fourteen-criterion matrix](V2_FORENSIC_AUDIT.md) remains the end-to-end
acceptance contract. GPU connectivity, enrollment consent, reviewed isolation,
real execution and full research-to-report behavior are not proven. Real
Grants.gov source access is recorded as a source investigation; repository
adapter implementation and end-to-end dashboard verification are subsequent work.
