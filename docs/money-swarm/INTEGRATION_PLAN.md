# Integration sequence and invariants

Extend the existing gateway, PostgreSQL migration set and React administration
client. Preserve desktop-local CRM compatibility; do not silently make local
contacts public or import unverified manufacturer profiles. Keep the volunteer
dispatcher separate from the shell-based agent worker.

The first reviewable change repairs funding transition authorization and example
provenance. Acceptance: no approval jump, no unauthenticated financial success,
one committed transition for concurrent identical actions, state/audit atomicity,
restart persistence and retained examples excluded from public metrics. Use a
disposable PostgreSQL instance and shared gateway/indexer migration tests.

Subsequent milestones normalize funding/hardware opportunities and source
snapshots; implement official source retrieval and incremental change tracking;
add fact-based eligibility and deterministic scoring; implement source-verified
hardware requests and measured/estimated energy analysis; add versioned evidence
packages; then bounded research agents and approved communications. Private
organization facts and contacts require authorization, with immutable approval
references on sensitive transitions.

Compute milestones require persistent opt-in identities and revocation, signed
artifact-bound leases, enforced resource limits, tested isolation, cancellation
and recovery. Only then enable an explicitly selected real GPU backend on
reachable, opted-in hardware. Measure result verification independently of receipt
attribution; keep donated/paid and measured/estimated accounting separate. Connect
approved project budgets before allocation, then wire actual API records into
the dashboard and prove the full workflow. No external submission, outreach,
purchase, contract acceptance, public enrollment or untrusted workload deployment
is authorized by an unattended agent action.

Follow-up work remains implementation scope, not an excuse to declare the mission
complete after this audit. No task tracker tools were exposed in the tool catalog
at inspection; `.todo` has not been edited.
