# X3 Foundry User Guide

## What is X3 Foundry?

X3 Foundry is an AI-powered dApp factory. You describe what you want to build, and X3 Foundry generates everything — the frontend, smart contracts, treasury, analytics, and marketplace listing — then deploys it across multiple blockchains.

**No coding required.** Just describe your idea.

## Browsing the Marketplace

Visit **https://apps.x3** to browse all dApps created through X3 Foundry.

### Marketplace Features
- **Featured Apps** — Curated selection of top dApps
- **Categories** — DeFi, NFTs, Games, AI Tools, Commerce, and more
- **Verified Badges** — Apps that have passed security audit
- **Risk Labels** — Clear risk indicators for each app
- **Revenue Stats** — Public revenue and usage data
- **Fee Transparency** — Clear fee schedule for every app

### App Details Page
Each app page shows:
- Description and screenshots
- Fee schedule (always visible)

## Creating a dApp with AI

### Step 1: Describe Your Idea

Go to **https://foundry.x3/new** and describe your dApp:

```
"Build me a token launchpad with presales, vesting, and whitelist"
"Create an NFT marketplace with auctions and royalties"
"Build a staking pool with rewards and lockups"
```

### Step 2: Review the Generation

X3 Foundry's AI agents will generate:
- **Frontend** — Complete React UI
- **Smart Contracts** — Solidity/X3 contracts
- **Fee Configuration** — Revenue model
- **Tests** — Unit and integration tests
- **Documentation** — README and API docs

### Step 3: Security Audit

Every dApp is automatically audited:
- Static analysis for vulnerabilities
- Fee transparency check
- Scam pattern detection
- License compliance check
- Principal safety verification

### Step 4: Revenue Simulation

See projected revenue before deploying:
- Expected monthly volume
- Platform fee revenue
- Creator earnings
- Gas costs
- Break-even analysis

### Step 5: Deploy

One click deploys your dApp to:
- Atlas Sphere (native)
- Ethereum, Polygon, Arbitrum, and more
- Cross-chain fee routing

## Understanding Fees

### What You Pay
- **Platform fee**: 2% of dApp revenue (default)
- **Deployment gas**: Network transaction fees
- **Subscription** (optional): $29–$99/month for premium features

### What You Never Pay
- Platform never takes your user deposits
- Platform never takes your collateral
- Platform never takes escrowed funds
- No hidden fees

### Fee Transparency
Every dApp shows its fee schedule:
- Before deployment (in the builder)
- Before every transaction (in the dApp UI)
- On the marketplace listing
- In the audit report

## Withdrawing Earnings

### How to Withdraw
1. Go to your Revenue Dashboard
2. Click "Withdraw"
3. Enter amount
4. Confirm transaction
5. Funds arrive in your wallet

### Withdrawal Rules
- Minimum withdrawal: 10 X3
- No withdrawal fees
- Instant settlement
- Available 24/7
- Withdraw to any wallet

## Forking Existing Apps

### How to Fork
1. Find an app in the marketplace
2. Click "Fork This App"
3. Customize the name and description
4. Review the generated code
5. Deploy your version

### Fork Rules
- Original creator gets optional remix royalty
- Platform fee still applies
- License must be respected
- Changes must pass security audit
- Fork lineage is public

### Common Questions

**Q: Do I need to know how to code?**
A: No. X3 Foundry's AI generates everything from your description.

**Q: What chains can I deploy to?**
A: Atlas Sphere, Ethereum, Polygon, Arbitrum, Optimism, Base, BSC, and 96+ more.

**Q: How much does it cost?**
A: Free tier: 3 apps/month with 2.5% platform fee. Builder: $29/month. Pro: $99/month.

**Q: Who owns the generated code?**
A: You do. You can export, modify, and self-host at any time.

**Q: Can I cancel my subscription?**
A: Yes, anytime. Your deployed apps continue running.
