# C14 — AI / ML compute & model provider credit programs

**Purpose:** Track AI/ML compute, foundation-model API, inference, embedding/RAG, dev environment, observability, synthetic-data, and agent-framework credit programs relevant to X3 Atomic Star.
**Use cases for X3:** AI dev tooling, embeddings for semantic search over chain data (transactions, events, addresses), AI copilots for the team, fine-tuning chain-specific classifiers (anomaly detection on intents/HTLCs), and CI/dev-experience tooling.
**Owner:** Subagent research (spawned 2026-09-05).
**Last updated:** 2026-09-05.

## How to read this file

Format follows `GRANTS_DATABASE.md`: `ID | Program | Covers | Award | Eligibility | URL | Notes (with "verified 2026-09-05" where applicable) | Status | Confidence`. `CONFIDENCE` is 1–5. `STATUS` is `RESEARCH`, `QUALIFIED`, `APPLIED`, `AWARDED`, `REJECTED`, `NOT-A-GRANT`, or `DEFUNCT`. URLs flagged "not verified" or "defunct" are clearly marked.

All rows below were investigated via `curl`/HEAD probes on 2026-09-05 unless explicitly marked otherwise. Verified URLs returned HTTP 200 from the tested endpoint.

**Honest gaps acknowledged:**
- **No real "credit program" pages were verified at the form-level** for these vendors. The market norm is (a) free tier / signup credit (a few dollars), (b) subscription with free monthly credits, or (c) pay-as-you-go. None of the providers in this round publish a public web URL for a "research grant" or "startup credit" program in the way C1.1–C1.4 (AWS Activate, GCP Startups, Microsoft for Startups, DigitalOcean Startups) do.
- The only adjacent AI-credit-style program actually verified to exist on the public web **in the broader C1 family already audited**: AWS Activate C1.1 (up to $200k includes AI startups; reduces friction for Bedrock), Google Cloud for Startups C1.2 ($100k with extra $350k for AI), and Microsoft for Startups C1.3 ($150k + OpenAI credits). I did **not** file these in C14 because they live in the C1 row family and the spec requested providers organized by company rather than by grant program. **Recommend: when applying to those, request Bedrock / Google AI / OpenAI credits specifically to cover AI workloads.**
- I deliberately did **NOT** fabricate URLs (e.g., `cohere.com/research-grants` is a real historical URL but currently 404 — found and dropped). Specific signup-credit dollar amounts (e.g., $5, $30) are stated as "subject to campaign" where the exact current amount is not authoritatively documented on the home page.
