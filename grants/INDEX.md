## Verification depth legend

Each row carries one of:
- **"Verified 2026-09-05"** + HTTP code in Notes column → URL probe succeeded (200/3xx) on the date the row was written
- **DEFUNCT** + date → program confirmed dead (e.g., Datadog /startups 404'd, Gitcoin legacy)
- **NOT-A-GRANT** → vendor has free tier but no startup program
- **RESEARCH conf 2–3** → URL exists but JS-rendered or requires auth, eligibility not fully confirmed
- **RESEARCH conf 1** → URL not verified, treated as candidate only
