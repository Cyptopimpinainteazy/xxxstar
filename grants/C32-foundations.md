## Summary

**Status:** C32 done. **Rows: 25** (target was 20; overshot by 5 because several near-tied URLs surfaced extra context). **Verified: 25 / 25** (every URL probed via curl on 2026-09-05 and the program existence verified via page content or known prior status).

**Quality rules followed:**
- Every URL was probed with curl (`xargs -P 12` parallel batches).
- HTTP status recorded for each (200 / 404 / 429 / DNS NXDOMAIN / etc.).
- No fabricated program names: rows are either real verified programs, or explicitly marked `NOT-A-GRANT` with the redirect/404/sparse-page note.
- Programs already covered in C12 (LF/ASF/Open Collective/GitHub Sponsors/NumFOCUS) are **re-included** only where this file adds verifiable fresh detail beyond the C12 row. C12 already covers seven foundations; C32 mostly adds L1/L2 chain foundations, modular-blockchain foundations, and discontinued/redirected programs (so future research agents don't waste cycles on them).

**Defunct / not-a-grant findings worth highlighting for the rest of the DB:**
- Web3 Foundation general grants program is **discontinued** (per raw README); use Polkadot OpenGov Treasury (C4.2) instead.
- Polygon's `/grants` URL 301-redirects to hadronfc.com (not a grant).
- `polygon.foundation` domain is for sale.
- `helium.foundation` does not resolve (NXDOMAIN); Helium Foundation is on `heliumfoundation.org` and currently has no public `/grants` page.
- `celestia.org/grants` 308-redirects; no live foundation grants program found.
- `filecoin.foundation` returns 200 but body is sparse placeholder; real Filecoin grants run via Protocol Labs / separate channels.
- `zksync.io/grants` 404; canonical ecosystem info is the zkSync Era ecosystem docs page.

**Recommended next actions** (not in scope of this file but worth telling the orchestrator):
- Verify with Aptos Foundation / Sui Foundation / NEAR Foundation / zkSync / Filecoin Foundation **directly via email** if a chain-specific integration is in scope.
- Apply to **Starknet Seed Grants** (C32.11) and **Rust Foundation Maintainers Fund** (C32.8) — both are current and have the strongest fit for a Rust+Substrate parachain with cross-VM ambitions.
